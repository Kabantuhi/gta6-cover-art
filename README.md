Neon Coast Cover Studio is an offline web app that turns any photo and caption into GTA 6-style cover art: pick a sample photo or upload your own, type a bold title and a script accent line, choose Square, Portrait or Wide, and export the finished cover as a PNG. Everything runs in the browser with no network requests, so your photo never leaves your device.

## Run it

```sh
node serve.ts
```

Then open the printed URL (http://localhost:8080) in your browser.
